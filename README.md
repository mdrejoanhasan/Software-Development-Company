# Rejoan Software — Software Development Company Website

A complete responsive 6-page software company website built with HTML5, CSS3, JavaScript and Bootstrap 5.

## Pages
- index.html — Home
- services.html — Services
- projects.html — Portfolio / Projects
- project-details.html — Dynamic project details
- about.html — About Us
- contact.html — Contact

## Features
- Responsive Bootstrap layout
- Full-width navigation with hover effects
- Hero carousel with 3 slides
- Services cards and expandable service details
- Portfolio category filter + pagination
- Dynamic project detail page
- Project image gallery with zoom/lightbox-style viewer
- Related projects
- Mission, vision, values
- Team cards with social links
- Career listings with Apply Now interaction
- Contact form confirmation modal
- Google Maps embed
- Live current date & time using JavaScript
- External CSS and JavaScript
- Internal page linking
- Mobile/tablet/desktop responsive design

## Run
Open `index.html` in a browser. Internet access is needed for Bootstrap Icons/Bootstrap CDN and the Google Maps embed.
